# شير سينباي — مشاركة الشاشة المباشرة برمز واحد

> اعرض شاشتك، شارك ملفًا، أو افتح غرفة صوتية — على أي جهاز، من أي شبكة، بلا تثبيت، ولا تسجيل، ولا حساب.
> تفتح الصفحة، تعطي الطرف الآخر رمزًا من ٦ خانات أو يمسح رمز QR، وتبدأ فورًا.

موقع ثابت بلا خادم، يؤسس اتصالًا مشفّرًا من طرف إلى طرف خلال ثوانٍ.

## مقدمة

المشكلة قديمة ومعروفة: للتشارك التقني حسابات وسجلات، وتثبيت برامج، وارتباط بشبكة واحدة، وقيود على الجوال.

شير سينباي يلغي ذلك كله:

- **صفر تثبيت** — صفحة واحدة تعمل من المتصفح مباشرة، دون أي برنامج.
- **صفر وسطاء** — لا خادم يحفظ أو يعبر عن بيانات الجلسة.
- **يعمل على آيفون وآيباد** — بميزة عرض الملفات مباشرة التي تتجاوز قيود مشاركة الشاشة على تلك الأجهزة.
- **يعمل بين أي شبكتين** — لا يشترط شبكة ولا اشتراط واي فاي واحدة.

## المزايا

### البث والعرض

| القدرة | التفاصيل |
|---|---|
| مشاركة الشاشة الكاملة | بثّ كل الشاشة بجودة قابلة للاختيار |
| مشاركة نافذة أو تبويب | اختيار مصدر واحد محدد للبث |
| عرض ملفات | PDF وصور وفيديو تُعرض داخل الجلسة — تعمل على الأجهزة المقيّدة |
| بثّ الكاميرا | كاميرا مباشرة بديلًا أو إضافة |
| غرفة صوتية | جلسة صوتية كاملة بلا صورة، للاجتماعات والمذاكرة |

### التفاعل الصوتي

- ميكروفون مستقل لكل مشارك مع فحص ذاتي قبل الدخول.
- مؤشر مرئي يحيط باسم المتحدث ويرافق صوته لحظيًا.
- أداة كتم ذكية: دفعة واحدة تكتم من يخصك دون إسكات الجميع.
- تحكم صاحب الغرفة: ميكروفونات مفتوحة للجميع، أو بإذنه فقط، مع كتم جماعي بضغطة.
- كتم محلي: كل مستخدم يكتم من يشاء عنده فقط.

### التفاعل المرئي

- مؤشرات بأسماء المشاركين فوق الشاشة يراها الجميع في الزمن الفعلي.
- قلم رسم بألوان متعددة وأسماك قابلة للضبط فوق الصورة.
- الرسم مقفل على الضيوف افتراضيًا — يُطلب الإذن ويُمنح بضغطة.
- محادثة نصية مدمجة مع تنبيهات دخول وخروج.

### التحكم الكامل بالغرفة

- كلمة سر تحمي الغرفة.
- موافقة يدوية قبل دخول أي مشاهد.
- طرد أي مشارك في أي لحظة.
- إيقاف العرض مؤقتًا مع استمرار الجلسة.
- تبديل مصدر العرض دون قصّ الجلسة.

### أدوات إضافية

- تسجيل الجلسة (فيديو) ولقطات تحفظ مباشرة.
- تكبير وتقريب، ملء الشاشة، نافذة عائمة.
- عداد مباشر لطول الجلسة مع شارة «يَعرض الآن».
- وضع ليلي ونهاري كامل، وواجهة عربية من البداية للنهاية.
- إعدادات محفوظة محليًا في المتصفح.

## كيف يعمل

```
الطرف الأول ──(رمز الغرفة)──► الواجهة (وسيط ترتيب الاتصال) ◄──(رمز الغرفة)── الطرف الثاني
                                       │
                                       ▼
                    اتصال مباشر P2P عبر WebRTC (صوت + صورة + تفاعل)
```

- من يؤسس الغرفة يصدر رمزًا فريدًا من ٦ خانات.
- يتواصل الطرفان لحظةً واحدة عبر خادم إشارات خفيف لترتيب اللقاء فقط.
- بعد التعارف يتم اتصال **مباشر بين الجهازين**، ويخرج الخادم من حلقة البيانات نهائيًا.
- الصوت والصورة والتفاعلات تمر من جهاز إلى جهاز فقط، مشفّرة ضمن البروتوكول (DTLS-SRTP).

المبدأ الجوهري: **الموقع وسيط ترتيب فقط، ولا يرفع ولا يخزّن شيئًا من الجلسة.**

## البدء السريع

### الاستخدام الفوري

1. افتح الرابط `https://robin-senpai.github.io/share-senpai/`.
2. أنشئ غرفة، انسخ الرمز وأرسله (أو اعرض رمز QR).
3. يدخل الطرف الآخر الرمز، وتوافق على دخوله إن فعّلت ذلك.
4. ابدأ البث أو العرض — والأدوات تتفاعل لحظيًا.

### النشر الذاتي

استضافة GitHub Pages مجانية تمامًا وتكفي الموقع:

```bash
git init -b main
git add index.html
git commit -m "شير سينباي"
git remote add origin https://github.com/<your-account>/share-senpai.git
git push -u origin main
```

ثم في إعدادات المستودع فعّل Pages على الفرع `main`، ويظهر الرابط خلال دقائق.

| الاستضافة | التكلفة | الوقت |
|---|---|---|
| GitHub Pages / Netlify / Vercel | مجاني | أقل من ٥ دقائق |
| خادم خاص مع PeerServer خاص | من اشتراك صغير | بيئة خاصة ومغلقة بالكامل |

## الأمان والخصوصية

- **من طرف إلى طرف**: الصوت والصورة والملفات تنتقل مشفّرة مباشرة بين الأجهزة.
- **لا خادم يحفظ البيانات**: لا يمر محتوى الجلسة بأي سيرفر.
- **غرفة مغلقة**: كلمة سر + موافقة قبل الدخول + طرد وقت الحاجة.
- **لا أثر**: لا حسابات، لا تتبع، لا بيانات شخصية تلمس الموقع.
