## المقدمة

أغلب أدوات مشاركة الشاشة تفرض على المستخدم: إنشاء حساب، وتثبيت برنامج، وربما الانضمام إلى الشبكة نفسها، أو الخضوع لقيود تمنع البث على الجوال.

**شير سينباي ينهي هذه الحلقة كلها:**

| الميزة الأساسية | كيف تُحل في شير سينباي |
| --- | --- |
| صفر تثبيت | ملف واحد يعمل من متصفح أي جهاز فورًا |
| صفر وسطاء | لا خادم يعبر أو يحفظ أي جزء من الجلسة |
| صفر قيود منصات | عرض الملفات يغطي آيفون وآيباد حيث يُمنع بث الشاشة |
| أي شبكتين | اتصال يعمل بين شبكات مختلفة دون اشتراط شبكة واحدة |

## أبرز المزايا

### البث والعرض

| القدرة | التفاصيل |
| --- | --- |
| الشاشة الكاملة | بث كامل الشاشة بجودة قابلة للاختيار |
| نافذة أو تبويب | بث مصدر محدد فقط إن رغبت |
| عرض ملفات | PDF وصور وفيديو تُعرض داخل الجلسة مباشرة |
| الكاميرا | بث مباشر من الكاميرا كبديل أو إضافة |
| غرفة صوتية | جلسة صوتية مكتملة بلا صورة |

### التفاعل الصوتي

- ميكروفون مستقل لكل مشارك مع فحص ذاتي قبل الدخول.
- مؤشر مرئي حول اسم المتحدث يتحرك مع صوته لحظيًا.
- أوضاع إدارة: ميكروفونات مفتوحة للجميع أو بإذن صاحب الغرفة فقط.
- كتم جماعي بضغطة واحدة، وكتم محلي لكل مستخدم.

### التفاعل المرئي

- مؤشرات بأسماء المشاركين فوق الشاشة، يراها الجميع في الزمن الفعلي.
- أدوات رسم على الصورة بألوان وأسماك متعددة.
- الرسم مقيّد على الضيوف افتراضيًا، ويُمنح الإذن بضغطة.
- محادثة نصية مدمجة مع تنبيهات بالدخول والخروج.

### التحكم الكامل بالغرفة

- كلمة سر تحمي الغرفة، وموافقة يدوية على كل مشاهد.
- إزالة أي مشارك، وإيقاف العرض مؤقتًا دون إغلاق الجلسة.
- تبديل مصدر العرض في أي لحظة.

### أدوات إضافية

- تسجيل الجلسة ولقطات تُحفظ مباشرة.
- تكبير وتقريب، نافذة عائمة، ملء الشاشة.
- عداد زمن الجلسة مع شارة «يَعرض الآن».
- وضع ليلي ونهاري وواجهة عربية كاملة.

## كيف يعمل

```
  الطرف 1 ──(رمز الغرفة)──► ┌──────────────┐ ◄──(رمز الغرفة)── الطرف 2
                            │ ترتيب الاتصال │
                            │  (وسيط فقط)   │
                            └──────┬───────┘
                                   ▼
                  اتصال مباشر P2P عبر WebRTC
                   صوت + صورة + تفاعل مشفر
```

1. من يبدأ الغرفة يُصدِر رمزًا فريدًا من ٦ خانات.
2. يتبادل الطرفان رسائل تعريف عبر خادم إشارات خفيف للحظات فقط.
3. بعد التعارف يُنشأ اتصال **مباشر** بين الجهازين ويغادر أي وسيط.
4. كل الصوت والصورة والتفاعلات تمر مشفرة (DTLS-SRTP) من جهاز إلى جهاز.

> **القاعدة الذهبية:** الموقع وسيط ترتيب فقط — لا يستمع، لا يخزن، ويرحل فور اكتمال التوصيل.

3. يدخل الطرف الآخر الرمز، وتوافق على دخوله إن فعّلت ذلك.
4. ابدأ البث أو العرض، وستظهر الأدوات لحظيًا.

## الأمان والخصوصية

- **نقل مشفر P2P**: الاتصال يُنشأ مباشرة بين الأجهزة، مشفرًا ضمن البروتوكول نفسه.
- **لا تخزين ولا تتبع**: لا كوكيز ولا أدوات تحليلات ولا حسابات.
- **غرفة مغلقة**: كلمة سر، وموافقة يدوية، وإدارة كاملة من صاحب الغرفة.
- **صفر جهات**: محتوى الجلسة لا يمر على أي خادم ثالث.

## الأسئلة الشائعة

**هل يحتاج الموقع إلى خادم خاص للتشغيل؟**
لا. يكفيه ملف واحد واستضافة ثابتة مجانية، لأن ترتيب الاتصال يتم عبر خدمة إشارات عامة.

**كم عدد المشاركين المدعوم؟**
عمليًا يتحدد بقدرة جهاز صاحب الغرفة وشبكته، لأن النقل مباشر مع كل طرف.

**ماذا عن الأجهزة المقيّدة مثل آيفون وآيباد؟**
استخدم ميزة عرض الملفات مباشرة: تعمل حتى على الأجهزة التي تمنع بث الشاشة.

**ماذا لو كانت الشبكات خلف جدار حماية صارم؟**
يعتمد الموقع على خوادم STUN/TURN عامة عند الحاجة، ويمكن تركيب خادم خاص للبيئات الأكثر صرامة.

**هل يصلح للمذاكرة والمراجعات؟**
نعم تمامًا: غرفة صوتية، ورسم تفاعلي، ومشاركة ملفات في جلسة واحدة.
